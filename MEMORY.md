- Экспонаты: 211 SVG-топологий (`images/topo/`), 21 растровый GUI-скриншот (`images/exhibits/`, 18 WLC + 3 обрезанных гибрида). Битых ссылок на файлы нет.
- dd: **159/159 готово** — все настоящие drag-drop с данными (полоса B добавила #545 и #1289 по сканам страниц).
- `sim` 35 — лаб-симуляции Cisco, ошибочно помеченные в дампе типом `dd`; переклассифицированы в тип `sim` через `type_overrides.json`. Не оцениваются, в экзамен/тренировку не попадают (`scorable()` → false). Показываются справочно на экране «Лаб-симуляции» (`browseSims()` в app.js, ссылка с домашнего экрана). meta: `sim_total` 35. Текст симуляции (единый run-on из дампа) форматируется `formatSimText()`: сворачивает boilerplate-инструкции интерфейса в details, задачи раскладывает списком с подзаголовками Task N.
- В Тренировке `sim` — отдельный выбираемый тип (чип «Симуляция», только practice, не exam). Пул: `domPool(true)` подмешивает симуляции при выборе `sim` или пустом фильтре («все»); экзамен `domPool(false)` их не берёт. В practice sim-карточка рендерится справочно (formatSimText + «не оценивается»), без проверки и без влияния на счётчик.
- Запуск тренажёра: `./run.sh` в корне проекта (поднимает `python3 -m http.server 8099`).
