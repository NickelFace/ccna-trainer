## Главное правило правок данных

`data/questions.json` и `data/meta.json` — **генерируемые файлы, руками не
трогать**. Любая правка делается в override-файле в `build/`, затем пересборка:

```bash
cd ccna-exam-simulator/build
python3 build_data.py
```

Скрипт читает банк из `../../ccna-project-archive/data/` и накладывает
все override-файлы. После пересборки — открыть тренажер в браузере и
проверить исправленный вопрос глазами.

## Какой override за что отвечает

| Файл | Что правит |
|---|---|
| `text_overrides.json` | текст вопроса + вынесенный CLI-блок (`t`, `cli`) |
| `option_fix.json` | варианты ответа, которые не распарсились из дампа |
| `classify_overrides.json` | домен вопроса (NF/NA/IPC/IPS/SEC/AUT) |
| `type_overrides.json` | тип вопроса (например, `ex` → `txt`, если экспоната нет) |
| `why_data.json` | объяснение по каждому варианту (scored MC; `why_parts/`, `merge_why.py`) |
| `exp_data.json` | объяснение drag-and-drop (поле `exp`; `exp_parts/`, `merge_exp.py`) |
| `dd_data.json` | данные drag-and-drop (элементы, корзины, ключ) |
| `svg_data.json` | привязка вопроса к перерисованной SVG-топологии |
| `drop_img.json` | список вопросов, где растровый экспонат больше не нужен |
| `exhibit_data.json` | классификация экспонатов; `"cropped": true` защищает обрезанный jpg от перезаписи |

Ключ везде — номер вопроса строкой: `"494": ...`.

## Типовые операции

**Исправить текст/вариант/ключ вопроса** — найти вопрос по `n` в
`data/questions.json` (только чтение!), внести правку в соответствующий
override, пересобрать, проверить в браузере.

**Добавить/перерисовать топологию** — рисовать строго по
`diagrams/diagram-style-prompt.md` (готовые `<symbol>`, палитра «цвет = тип
устройства», чек-лист в конце файла обязателен). Файл кладётся в
`images/topo/qN.svg`, привязка — в `build/svg_data.json`, пересборка.

**Обрезать растровый экспонат** — обрезать `images/exhibits/qN.jpg` на месте,
затем в `exhibit_data.json` добавить записи `"cropped": true`, иначе
пересборка вернёт исходный кадр из архива.

## Проверка после правок (чек-лист)

1. `python3 build_data.py` завершился без ошибок, счётчик `questions: 1395`.
2. В браузере: исправленный вопрос отображается корректно.
3. Число изменённых вопросов равно ожидаемому (можно сравнить
   questions.json до/после).
4. Обновить `MEMORY.md`, если изменилось состояние банка или появились
   новые договорённости.
