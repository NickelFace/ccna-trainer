# Первый промпт для Claude Code

Скопировать целиком в Claude Code, запущенный в корне репозитория `ccna-trainer`.

---

Мы делаем Android-приложение CCNA Trainer отдельным продуктом внутри этого же репозитория.
Веб-версия в `ccna-exam-simulator/` остаётся работать как есть — не ломай её.

В папке `design_handoff_ccna_android/` лежит вся постановка:

- `README.md` — дизайн-спека: токены (цвета, шрифты, шкала, радиусы, тач-таргеты), 9 экранов
  с точной вёрсткой и копией, интерактив, модель состояния, SRS, шаблон ИИ-промпта, ассеты.
- `ANDROID_APP.md` — структура подпапки `ccna-mobile/`, скрипты сборки, синхронизация банка,
  таблица платформенных правок Android, порядок работ.
- `Redesign.dc.html` — макеты (9 экранов, 390×844) + разбор проблем текущего UI. Открывается
  в браузере, `support.js` должен лежать рядом.
- `Current UI.dc.html` — текущие экраны, воссозданные из кода: референс «от чего уходим».

Важно: HTML-файлы — **дизайн-референсы**, а не код для копирования. Инлайн-стили и статичные
данные там только для показа. Реализуй экраны заново по спеке в стеке из `ANDROID_APP.md`
(ванильный JS + esbuild + Capacitor, без фреймворка, офлайн, без CDN).

Начни так:

1. Прочитай `design_handoff_ccna_android/README.md` и `ANDROID_APP.md` целиком.
2. Прочитай `ccna-exam-simulator/assets/js/app.js` — оттуда переиспользуется вся математика:
   `weightedPick`, `scaled = 300 + pct*700` с порогом 825, `isCorrect`, `ddCorrect`/`ddExpected`/
   `ddNeeded`, разбор `q.cli`, логика показа per-option rationale. Не переписывай её с нуля.
3. Посмотри `ccna-exam-simulator/data/meta.json` и структуру одного вопроса из
   `data/questions.json` (описание модели — в `ccna-exam-simulator/README.md`).
4. Покажи мне план: файлы, которые создашь на шаге 1–2 из «Порядка работ», и что именно
   вынесешь в `ccna-mobile/src/engine/`. Дождись подтверждения, потом пиши код.

Требования, которые нельзя потерять по пути:

- Приложение полностью офлайн: банк, картинки exhibit, шрифты и иконки бандлятся локально.
- Банк вопросов не дублируется в git — `ccna-mobile` берёт его скриптом `sync-data` из
  `ccna-exam-simulator/data` и `images/exhibits`, а `dist/` в `.gitignore`.
- Прогресс сессии, история попыток и SRS сохраняются на устройстве и восстанавливаются после
  того, как Android выгрузил приложение из памяти.
- Никакого HTML5 drag & drop: сопоставления делаются тапом (экран 05 в макетах).
- Тач-таргеты главных действий ≥48dp, все липкие панели учитывают `env(safe-area-inset-*)`.
- Системная «назад» — шаг назад по стеку, а не выход из приложения.
- Логика движка (`engine/`) покрывается unit-тестами: скоринг, выборка по весам доменов,
  интервалы SRS, проверка drag-drop-ответов с дистракторами.
