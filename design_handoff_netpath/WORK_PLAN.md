- [ ] Три раскраски: на светлом (`#16181D`/`#16181D`/`#C9A24A`), на тёмном (`#F7F4EE`/`#F7F4EE`/`#C9A24A`), монохром (`#8A8578`).

### A2. Adaptive icon для Android
- [ ] `foreground` — символ векторным drawable, отступ от края контейнера 20% (безопасная зона под любую маску).
- [ ] `background` — отдельный слой, сплошной `#16181D`. Не запекать фон в foreground: маска срежет силуэт.
- [ ] `monochrome` — слой для themed icons Android 13+: силуэт одним цветом, фон прозрачный.
- [ ] Проверить под тремя масками устройства: squircle, круг, скруглённый квадрат.

**Приёмка:** ни одна маска не срезает ступени; в круглой маске силуэт визуально по центру.

### A3. Растровые экспорты
- [ ] mdpi 48, hdpi 72, xhdpi 96, xxhdpi 144, xxxhdpi 192.
- [ ] Play Store — 512×512 PNG без прозрачности.
- [ ] Заменить старую иконку во всех плотностях, убрать неиспользуемые файлы.

**Приёмка:** на реальном устройстве иконка чёткая, без ореолов и артефактов ресайза.

### A4. Название приложения
