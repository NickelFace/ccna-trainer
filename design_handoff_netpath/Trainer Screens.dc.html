Network Access Вопрос 604

A switch receives a frame with an unknown destination MAC address. What does it do?

A Drops the frame
Sends it back out the port it arrived on
Floods it out all ports in the VLAN except the ingress port
D Asks the default gateway to resolve it
✗ Неверно · ключ: C
B. Sends it back out the port it arrived on ✗ неверно · твой выбор

Отправка обратно во входящий порт запрещена правилом фильтрации источника: иначе на уровне доступа возникали бы петли из ничего.

C. Floods it out all ports in the VLAN except the ingress port ✓ верно

Неизвестный юникаст коммутатор флудит: рассылает кадр во все порты своего VLAN, кроме входящего. Ответ узла попадёт в таблицу MAC, и дальше трафик пойдёт точечно.

Что здесь меняется — только оформление
Ни одной новой функции. Все экраны, кнопки и подписи уже есть в app.js. Строки взяты из I18N.ru дословно — «☆ на потом», «Проверить», «шкала 300–1000 · порог 825», «✗ неверно · твой выбор». Экзамен тёмный, тренировка светлая. В коде это одна и та же вёрстка; хром режима — единственное добавление к структуре, и оно нулевой стоимости: в экзамене нет пояснений и есть таймер, в тренировке наоборот. CLI стал настоящим кодом. В продукте это уже выделяемый моноширинный текст, а не скриншот — здесь он оформлен как терминальный блок и варианты-команды тоже моноширинные. Красный #B3453A — единственный цвет, которого нет на лендинге. Приглушён под палитру, используется только для вердикта ошибки.
