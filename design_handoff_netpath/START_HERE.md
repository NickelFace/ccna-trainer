# NetPath — пакет передачи в разработку

Дизайн-пакет: ребрендинг тренажёра для подготовки к экзамену 200-301 (`ccna.maks.top`), новый лендинг и иконка мобильного приложения.

## Порядок чтения

1. **`WORK_PLAN.md`** — начать здесь. Что делать, в каком порядке, критерии приёмки, что НЕ входит в объём, открытые вопросы к владельцу.
2. **`README.md`** — спецификация: все цвета, шрифты, отступы, размеры, геометрия иконки, посекционное описание лендинга, копирайт дословно.
3. **`Site Landing.dc.html`** — макет лендинга. Открывается в браузере напрямую.
4. **`Logo Directions.dc.html`** — доска бренда: варианты логотипа и иконки. Утверждена иконка **2c** («ступени»), остальное — контекст решения.

`support.js` — runtime прототипов, в продакшн не переносится.

## Коротко о задаче

Два независимых трека:

- **A. Мобильное приложение** (`ccna-mobile`) — внедрить утверждённую иконку: adaptive icon, monochrome-слой, растровые экспорты под все плотности.
- **B. Лендинг** — пересобрать по макету: меньше текста, объяснения через интерфейсные элементы, новая секция «Три режима тренажёра», кнопка скачивания APK, рабочая локализация RU/EN.

Бренд снят с чужой торговой марки: рабочее имя **NetPath** (вынесено в параметр — владелец меняет его после сдачи экзамена), название экзамена используется только как дескриптор, в футере обязательный дисклеймер о неаффилированности с Cisco Systems.

## Важное

Файлы `.dc.html` — **дизайн-референсы**, а не продакшн-код. Задача — воспроизвести макеты в существующем окружении проекта его же паттернами. Fidelity высокий: значения финальные, копирайт дословный.

Решения владельца закрыты: имя **NetPath**, заголовки — Playfair Display для RU и Instrument Serif для EN, ссылка на сборку — страница релизов GitHub, CTA режимов ведут deep-link'ами. Тренажёр — SPA на одном адресе без роутинга, это сохраняется: режимы открываются query-параметром `?mode=`, новых URL-путей не вводить. Блокировок нет.

Пять пунктов разведки в Фазе 0 `WORK_PLAN.md` всё равно закрыть первыми — прототипы не знают, что уже есть в кодовой базе.
