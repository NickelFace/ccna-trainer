# NetPath — пакет передачи в разработку

Дизайн-пакет по проекту [NickelFace/ccna-trainer](https://github.com/NickelFace/ccna-trainer): ребрендинг, новый лендинг, редизайн экранов веб-тренажёра и иконка Android-приложения.

## Порядок чтения

1. **`WORK_PLAN.md`** — начать здесь. Что делать, в каком порядке, критерии приёмки, что НЕ входит в объём.
2. **`TRAINER.md`** — спецификация восьми экранов тренажёра с привязкой каждого к функции в `app.js`.
3. **`README.md`** — спецификация лендинга и бренда: цвета, шрифты, отступы, геометрия иконки, посекционное описание, копирайт дословно.
4. **`github.md`** — карта «экран → файл в репозитории» и состояние синхронизации.
5. Макеты: **`Trainer Screens.dc.html`**, **`Site Landing.dc.html`**, **`Logo Directions.dc.html`**, **`Type Cyrillic Test.dc.html`**. Открываются в браузере напрямую.

`support.js` — runtime прототипов, в продакшн не переносится.

## Три трека

**A. Иконка Android-приложения** (`ccna-mobile`) — внедрить утверждённый знак 2c: adaptive icon, monochrome-слой, растровые экспорты. Заменяет заглушку `res/drawable/ic_launcher_foreground.xml`, которую README мобильного приложения сам помечает как временную. Ни от чего не зависит, можно запускать первым.

**B. Лендинг** (`ccna-exam-simulator`) — переработать первый экран: меньше текста, объяснения через интерфейсные элементы, секция «Три режима тренажёра», кнопка скачивания APK, механизм локализации RU/EN.

**C. Экраны тренажёра** — редизайн восьми существующих экранов веб-симулятора. **Ни одной новой функции**: все кнопки, состояния и подписи уже есть в `app.js`, строки взяты из `I18N.ru` дословно. Это работа по оформлению, не по логике.

## Что уже решено

- Имя бренда: **NetPath**, финально.
- Заголовки: **Playfair Display** для русского, **Instrument Serif** для английского (у Instrument Serif нет кириллицы — обоснование и отклонённые кандидаты в `Type Cyrillic Test.dc.html`).
- Ссылка на сборку: `https://github.com/NickelFace/ccna-trainer/releases/latest`.
- Режимы открываются query-параметром `?mode=exam|custom|practice`. **Тренажёр — SPA без роутинга, это сохраняется: новых URL-путей не вводить.**
- EN-версия текстов лендинга — позже, сейчас только механизм.

## Важное

Файлы `.dc.html` — **дизайн-референсы**, а не продакшн-код. Задача — воспроизвести макеты в существующем окружении проекта его же паттернами: веб-симулятор это ванильный JS без сборки и без фреймворка, шаблоны собираются строками в `app.js`. Не тащить туда React.

Fidelity высокий: значения финальные, копирайт дословный. Единственное лоу-фай место — содержимое вопросов в макетах (тексты заданий, CLI-вывод): это иллюстрации типового вопроса, а не данные из банка.
